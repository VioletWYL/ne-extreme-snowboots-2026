## 定制基准
- **采购对象**：男性 · `180cm / 80kg` · 日常运动鞋码 `EU 44 (275–280mm)` · 冬季裤码 `CN/EU 48`
- **适用环境**：东北冬季极寒雪野徒步（`-20°C` 至 `-40°C`，涵盖哈尔滨、雪乡羊草山、长白山、大兴安岭、漠河）
- **覆盖矩阵**：迪卡侬（3款）+ 平价口碑（4款）+ 顶级性能（3款）共 10 款真防水防寒徒步靴
